# SpeedX Tracking

Next.js App Router site for SpeedX package tracking, coverage, ship-with-us guides, and support.

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

## Scripts

| Command         | Description                |
| --------------- | -------------------------- |
| `npm run dev`   | Start Next.js (Turbopack)  |
| `npm run build` | Create a production build  |
| `npm start`     | Serve the production build |
| `npm run lint`  | Run ESLint                 |
